HomeChefHub - Nearby Dishes Feature

Dishes Near Me

Find homemade meals available for delivery near your location

Features Implemented:
  • Real-time geolocation detection
  • Adjustable search radius (3-15 km)
  • Distance display for each dish
  • Automatic refresh on radius change
  • Error handling for permissions
  • Responsive design
Technical Implementation
  • Browser Geolocation API
  • Haversine distance calculation
  • RESTful API integration
  • Real-time search updates
  • Error handling & fallbacks
User Experience
  • One-click location detection
  • Intuitive radius slider
  • Clear distance indicators
  • Instant search results
  • Mobile-friendly interface
API Endpoint

GET /api/chefs-mvp/nearby-dishes/?latitude=X&longitude=Y&radius=Z

Parameters:
  • latitude: User's latitude
  • longitude: User's longitude
  • radius: Search radius in km (3-15)
Response:
{
  "dishes": [...],
  "search_location": {
    "latitude": 12.9716,
    "longitude": 77.5946,
    "radius_km": 3
  },
  "total_found": 4
}

Make sure the Django server is running: python manage.py runserver
